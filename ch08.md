## Basics

### General Group 

There is only one operator and one object (or set) in *group*, where the operator is **abstracted** as $\diamond$ and identity as $\boldsymbol{1}$. But they are not specified concretely, the operator $\diamond$ can be $+$ or $*$, and the identity $\bold{1}$ can be $0$ or $1$ for addition and multiplication respectively. So group with $(+, 0)$ is called *AddGroup*, and group with $(*, 1)$ is called *MulGroup*. In lean4, the default *Group* is *MulGroup*.

**One Class**
```lean
class One₁ (α : Type) where
  /-- The element one -/
  one : α

@[inherit_doc]
notation "𝟙" => One₁.one

example {α : Type} [One₁ α] : α := 𝟙

example {α : Type} [One₁ α] : (𝟙 : α) = 𝟙 := rfl
```
One class, denoted as "𝟙",  is used to show the existence of identity, $\bold{1}$ for multplicative, and $\bold{0}$ for additive, note that $one \ne 1$. 

**Dia Class**
```lean
class Dia₁ (α : Type) where
  dia : α → α → α

infixl:70 " ⋄ "   => Dia₁.dia
```
Dia class, denoted as diamond operator $\diamond$, defines the function of binary operation of type $\alpha \rightarrow \alpha \rightarrow \alpha$.

**Semigroup Class**
```lean
class Semigroup₁ (α : Type) extends toDia₁ : Dia₁ α where
  /-- Diamond is associative -/
  dia_assoc : ∀ a b c : α, a ⋄ b ⋄ c = a ⋄ (b ⋄ c)
```
Semigroup class is used to define the associative property on operator $\diamond$, so we need to extend Dia class first. 


**DiaOneClass Class**
```lean
class DiaOneClass₁ (α : Type) extends One₁ α, Dia₁ α where
  /-- One is a left neutral element for diamond. -/
  one_dia : ∀ a : α, 𝟙 ⋄ a = a
  /-- One is a right neutral element for diamond -/
  dia_one : ∀ a : α, a ⋄ 𝟙 = a
```
DiaOneClass class is specially used to define binary operation properties of $\diamond$ specially with identity element $\bold{1}$, so we also need to extend Dia class and One class first.

**Monoid Class**

```lean
class Monoid₁ (α : Type) extends Semigroup₁ α, DiaOneClass₁ α
```
Monoid class is a combination of Semigroup and DiaOneClass, which has axioms:
- operation closure on operator $\diamond$ with type $\alpha \rightarrow \alpha \rightarrow \alpha$.
- identity and its binary operations, $1 \diamond a = a \diamond 1$.
- associative, $a \cdot b \cdot c = a \diamond (b \diamond c)$. 

**Inv Class**
```lean
class Inv₁ (α : Type) where
  /-- The inversion function -/
  inv : α → α

@[inherit_doc]
postfix:max "⁻¹" => Inv₁.inv
```
Inv class, denoted as $^{-1}$,defines the inverse function $\alpha \rightarrow \alpha$.

**Group**
```
class Group₁ (G : Type) extends Monoid₁ G, Inv₁ G where
  inv_dia : ∀ a : G, a⁻¹ ⋄ a = 
```
Group class defines the inverse property $a^{-1} \cdot a = 1$, it is a function of $\alpha \rightarrow \alpha \rightarrow \alpha$ on operator $\diamond$, and has inverse function $\alpha \rightarrow \alpha$ on $^{-1}$. So we need to extend Monoid and Inv class first.

### Addition Group

*Group* with $(\diamond, \bold{1})$ cannot be used directly, operator and identiy must be specified respectively, so *Group* with $(+,0)$ is called *AddGroup*.

**AddSemigroup Class**
```
class AddSemigroup₃ (α : Type) extends Add α where
  /-- Addition is associative -/
  add_assoc₃ : ∀ a b c : α, a + b + c = a + (b + c)
```
*Add* is a concrete operator class of type $\alpha \rightarrow \alpha \rightarrow \alpha$, denoted as $+$. It is corresponded with `Dia` class in general `Group` structure. In this case, `AddSemigroup` is corresponded with `Semigroup` in general `Group` structure, in which the operator $\diamond$ of association is replaced with $+$.

**Semigroup Class**
```lean
@[to_additive AddSemigroup₃]
class Semigroup₃ (α : Type) extends Mul α where
  /-- Multiplication is associative -/
  mul_assoc₃ : ∀ a b c : α, a * b * c = a * (b * c)
```
In lean4, multipliation $*$ is the default operator, so `Semingroup` is  $*$ versioned of `AddSemigroup`.

**AddMonoid Class**
```lean
class AddMonoid₃ (α : Type) extends AddSemigroup₃ α, AddZeroClass α
```
Similar with `Monoid` in general `Group` class structure, `AddMonoid` must extend `AddSemigroup` and `AddZeroClass`, where `AddZeroClass`  corresponds with `DiaOneClass`  specially for operator $+$ and identity $0$. 

**AddCommSemigroup Class**
```lean
class AddCommSemigroup₃ (α : Type) extends AddSemigroup₃ α where
  add_comm : ∀ a b : α, a + b = b + a
```
AddCommSemigroup define the commutative property of `AddSemigroup`.

**AddCommMonoid Class**
```lean
class AddCommMonoid₃ (α : Type) extends AddMonoid₃ α, AddCommSemigroup₃ α
```
AddCommMonoid is a combination of `AddMonoid`  and `AddCommSemigroup`.

**AddGroup Class**
```lean
class AddGroup₃ (G : Type) extends AddMonoid₃ G, Neg G where
  neg_add : ∀ a : G, -a + a = 0
```
Similar with general `Group` class, `Neg` class is corresponded with `Inv` specially for operator $+$, and $a^{-1} \diamond a = \bold{1}$ in `inv_dia` is replaced with $-a + a = 0$ in `neg_add`.

### Multiplicative Group

```lean
@[to_additive AddGroup₃]
class Group₃ (G : Type) extends Monoid₃ G, Inv G where
  inv_mul : ∀ a : G, a⁻¹ * a = 1
```
In lean4, the default operator in group is $*$, so actually (multiplicative) *Group* is implemented, and then use `@[to_...]` to automatically generate code for *AddGroup*.

### Additive Commutative Group 

Additive commutative group is an additive group with commutative property.

```lean
class AddCommGroup₃ (G : Type) extends AddGroup₃ G, AddCommMonoid₃ G
```
In this case, we need to inherit additive group property from `AddGroup` and commutative property from `AddCommMonoid`. Usually we have a beautiful name for `AddCommGroup`, that is *Abelian Group*. But in lean4 $*$ is the default one, so we might see that *Abelian Group* is used to refer multiplicative *Group*.

### Ring

Ring is composed of two components, one is object, the other one is scalar, but both of them are defined by the same set $R$ :
- the object is an `AddGroup` with operator $+$.
- the scalar is an (multiplicative) `Monoid` with operator $*$. 
- operations on $*$ with $0$ will be absorbed into $0$.
- mixed operations on $+$ and $*$ satisfy distributive property.

```lean
class Ring₃ (R : Type) extends AddGroup₃ R, Monoid₃ R, MulZeroClass R where
  /-- Multiplication is left distributive over addition -/
  left_distrib : ∀ a b c : R, a * (b + c) = a * b + a * c
  /-- Multiplication is right distributive over addition -/
  right_distrib : ∀ a b c : R, (a + b) * c = a * c + b * c
```
Notice that, Ring does not have commutative property on both operators,  $+$ of `AddGroup` and $*$ of `Monoid`. 

### Additive Commutative Group

Additive commutative group is a additive group with commutative property.

```
class AddCommSemigroup₃ (α : Type) extends AddSemigroup₃ α where
  add_comm : ∀ a b : α, a + b = b + a

@[to_additive AddCommSemigroup₃]
class CommSemigroup₃ (α : Type) extends Semigroup₃ α where
  mul_comm : ∀ a b : α, a * b = b * a

class AddCommMonoid₃ (α : Type) extends AddMonoid₃ α, AddCommSemigroup₃ α

@[to_additive AddCommMonoid₃]
class CommMonoid₃ (α : Type) extends Monoid₃ α, CommSemigroup₃ α

class AddCommGroup₃ (G : Type) extends AddGroup₃ G, AddCommMonoid₃ G
```
Note that, in general `AddSemigroup` does not have additive commutative property, so we need to add its definition manually in `AddCommSemigroup`. It is clear to see that `AddSemigroup` is also an **abstract** class, we need to instantiate it before using. We can see an instance of `AddCommGroup` with type $\alpha$ instantiated with `Ring`, and the commutative property will be instantiated by utilizing `Ring`'s basic properties (additive association, distribution, etc...):
```lean
instance {R : Type} [Ring₃ R] : AddCommGroup₃ R :=
{
  add_comm := by
    intro a b
    have : a + (a + b + b) = a + (b + a + b) := calc
      a + (a + b + b) = (a + a) + (b + b) := by simp [add_assoc₃, add_assoc₃]
      _ = (1 * a + 1 * a) + (1 * b + 1 * b) := by simp
      _ = (1 + 1) * a + (1 + 1) * b := by simp [Ring₃.right_distrib]
      _ = (1 + 1) * (a + b) := by simp [Ring₃.left_distrib]
      _ = 1 * (a + b) + 1 * (a + b) := by simp [Ring₃.right_distrib]
      _ = (a + b) + (a + b) := by simp
      _ = a + (b + a + b) := by simp [add_assoc₃]
    exact add_right_cancel₃ (add_left_cancel₃ this)
}
```

### Module

Similar with *Ring*, *Module* also consists of two components, one is an object, the other one is a scalar. The difference is that they are defined on two different sets $M$ and $R$ respectively. And there are three operators amond them :
- the object $M$ is a `AddCommGroup` (or additive abelian group) with operator $+$
- the scalar $R$ is a `Ring` with two operators, $*$ and $+$
- operation between object and scalar is often **abstracted** as scalar-mul `SMul` symbol $\cdot$ with type $\alpha \rightarrow \beta \rightarrow \beta$ . That is, any element from `Ring` is absorbed in `AddCommGroup`. A few operations of scalar-mul `SMul` are listed below :
    - $(a * b) \cdot m = a \cdot b \cdot m$
    - $(a + b) \cdot m = a \cdot m + b \cdot m$
    - $a \cdot (m + n) = a \cdot m + a \cdot n$

```lean
class SMul₃ (α : Type) (β : Type) where
  /-- Scalar multiplication -/
  smul : α → β → β

infixr:73 " • " => SMul₃.smul

class Module₁ (R : Type) [Ring₃ R] (M : Type) [AddCommGroup₃ M] extends SMul₃ R M where
  zero_smul : ∀ m : M, (0 : R) • m = 0
  one_smul : ∀ m : M, (1 : R) • m = m
  mul_smul : ∀ (a b : R) (m : M), (a * b) • m = a • b • m
  add_smul : ∀ (a b : R) (m : M), (a + b) • m = a • m + b • m
  smul_add : ∀ (a : R) (m n : M), a • (m + n) = a • m + a • n
```
Notice that `Module` class is also an abstract one, not instantiated yet, specially including a few operations of $\cdot$ :
1. `SMul` operator $\cdot$, need to implement `smul` function
2. $1 \cdot m$ operation, need to implement `one_mul` function
3. $m \cdot 1$ operation, need to implement `mul_one` function
4. $(a * b) \cdot m$ operation, need to implement `mul_smul` function
5. $(a + b) \cdot m$ operation, need to implement `add_smul` function
6. $a \cdot (m + n)$ operation, need to implement `smul_add` function

For instance, we can instantiate:
- `SMul` operator $\cdot$ with multiplication $*$
- object $M$ with `AddCommGroup Ring`
- scalar $R$ with `Ring`
then :
1. `smul`  $\alpha \rightarrow \alpha \rightarrow \alpha$ is instantiated with $\text{AddCommGroup Ring} \rightarrow \text{Ring} \rightarrow \text{Ring}$
2. `one_mul` $1 \cdot m$ is instantiated with $1 * m$
3. `mul_one` $m \cdot 1$ is instantiated with $m * 1$
4. `mul_smul` $(a * b) \cdot m$ is instantiated with $(a * b) * m$
5. `add_mul` $(a + b) \cdot m$ is instantiated with $(a + b) * m$
6. `mul_add` $a \cdot (m + n)$ is instantiated with $a * (m + n)$

```lean
instance selfModule (R : Type) [Ring₃ R] : Module₁ R R where
  smul := fun r s ↦ r*s
  zero_smul := zero_mul
  one_smul := one_mul
  mul_smul := mul_assoc₃
  add_smul := Ring₃.right_distrib
  smul_add := Ring₃.left_distrib
```
Notice that `selfModule` is not a fully instantiated instance of `Module`, since `AddCommGroup Ring` and `Ring` are still abstract classes. For example, `Ring` can be further instantiated with $\Z$, $\mathbb{F}[X]$, etc ...

## Mophism

### Monoid Homomorphism
Homomorphism on `Monoid` which is operator-identity pair of $(*, 1)$,
```lean
@[ext]
structure MonoidHom₁ (G H : Type) [Monoid G] [Monoid H]  where
  toFun : G → H
  map_one : toFun 1 = 1
  map_mul : ∀ g g', toFun (g * g') = toFun g * toFun g'
```
is defined with :
- `toFunc` is one function of $\text{Monoid} \rightarrow \text{Monoid}$
- `map_one` shows identity map
- `map_mul` shows operation preservation of map

Below shows homomorphism on `AddMonoid` with operator-identity pair of $(+, 0)$,
```lean
@[ext]
structure AddMonoidHom₁ (G H : Type) [AddMonoid G] [AddMonoid H]  where
  toFun : G → H
  map_zero : toFun 0 = 0
  map_add : ∀ g g', toFun (g + g') = toFun g + toFun g'
```

### Ring Homomorphism

```lean
@[ext]
structure RingHom₁ (R S : Type) [Ring R] [Ring S] extends MonoidHom₁ R S, AddMonoidHom₁ R S
```
Ring has two operators $+$ and $*$, so `RingHom` can be easily obtained by extending `MonoidHom` and `AddMonoidHom` :
- $1 \mapsto 1$ from `MonoidHom`
- $f (a * b) = f(a) * f(b)$ from `MonoidHom`
- $0 \mapsto 0$ from `AddMonoidHom`
- $g (a + b) = g(a) + g(b)$ from `AddMonoidHom`

### Homomorphism Class
```lean
class MonoidHomClass₁ (F : Type) (M N : Type) [Monoid M] [Monoid N] where
  toFun : F → M → N
  map_one : ∀ f : F, toFun f 1 = 1
  map_mul : ∀ f g g', toFun f (g * g') = toFun f g * toFun f g'
```
`MonoidHomClass` is a class (group) of `MonoidHom` with type $\text{Monoid} \rightarrow \text{Monoid}$.

Another kind of definition of `MonoidHomClass` and `RingHomClass` :
```lean
instance (M N : Type) [Monoid M] [Monoid N] : MonoidHomClass₂ (MonoidHom₁ M N) M N where
  toFun := MonoidHom₁.toFun
  map_one := fun f ↦ f.map_one
  map_mul := fun f ↦ f.map_mul

instance (R S : Type) [Ring R] [Ring S] : MonoidHomClass₂ (RingHom₁ R S) R S where
  toFun := fun f ↦ f.toMonoidHom₁.toFun
  map_one := fun f ↦ f.toMonoidHom₁.map_one
  map_mul := fun f ↦ f.toMonoidHom₁.map_mul
```
Since already `RingHom` extends `MonoidHom`, we can directly use `toMonoidHom` to get the functionality of monoid homomorphism.

### Order Preserve Homomorphism

Let's see an example of order preserve homomorphism on monoid,
```lean
@[ext]
structure OrderPresHom (α β : Type) [LE α] [LE β] where
  toFun : α → β
  le_of_le : ∀ a a', a ≤ a' → toFun a ≤ toFun a'

@[ext]
structure OrderPresMonoidHom (M N : Type) [Monoid M] [LE M] [Monoid N] [LE N] extends
MonoidHom₁ M N, OrderPresHom M N
```
`OrderPresMonoidHom` preserves order operation $\le$ on `Monoid`. 
```lean
class OrderPresHomClass (F : Type) (α β : outParam Type) [LE α] [LE β]

instance (α β : Type) [LE α] [LE β] : OrderPresHomClass (OrderPresHom α β) α β where

instance (α β : Type) [LE α] [Monoid α] [LE β] [Monoid β] :
    OrderPresHomClass (OrderPresMonoidHom α β) α β where

instance (α β : Type) [LE α] [Monoid α] [LE β] [Monoid β] :
    MonoidHomClass₃ (OrderPresMonoidHom α β) α β
  where
    coe := fun f ↦ f.toOrderPresHom.toFun
    coe_injective' _ _ := OrderPresMonoidHom.ext
    map_one := fun f ↦ f.toMonoidHom₁.map_one
    map_mul := fun f ↦ f.toMonoidHom₁.map_mul
```
`OrderPresHomClass` is the class (group) of order preserve homomorphism, and `MonoidHomClass` is the class (group) of order preseve homomorphism on `Monoid`. 

## Group

Let's see an example of `Monoid` (with operator $*$) homomorphism, which denoted as $M \rightarrow* N$
```lean
example {M N : Type*} [Monoid M] [Monoid N] (x y : M) (f : M →* N) : f (x * y) = f x * f y :=
  f.map_mul x y
```

and an example of Abelian group (also `AddCommGroup`),
```lean
example {G : Type*} [AddCommGroup G] (x y z : G) : z + x + (y - z - x) = y := by
  abel
```

### Group Homomorphism
The definition of group homomorphism is, if a function $f : G \rightarrow H$ satisfy $f (x * y) = f(x) * f(y)$, then we say `f` is a group homomorphism:
```lean
example {G H : Type*} [Group G] [Group H] (f : G → H) (h : ∀ x y, f (x * y) = f x * f y) :
    G →* H :=
  MonoidHom.mk' f h
```

### Group Isomorphism
If a group homomorphism $f : G \rightarrow *H$ is a bijective function, then we say `f` is a group isomorphism:
```lean
noncomputable example {G H : Type*} [Group G] [Group H]
    (f : G →* H) (h : Function.Bijective f) :
    G ≃* H :=
  MulEquiv.ofBijective f h
```
### Subgroup

Let's see an example of subgroup, $\mathbb{Z}$  is a subgroup of $\mathbb{Q}$. Subgroup needs to satisfy four conditions:
1. coercion function $\mathbb{Z} \rightarrow \mathbb{Q}$, that is any element from $\mathbb{Z}$ can be converted to $\mathbb{Q}$, i.e. $a \in \mathbb{Z}, (a : \mathbb{Q}) = a$ 
2. identity existence, since subgroup is also a group. $0$ for `AddGroup` and $1$ for `Group`
3. inverse, same reason. $-a$ for `AddGroup` and $a^{-1}$ for `Group`
4. addition (or multiplication) closure, $\alpha \rightarrow \alpha \rightarrow \alpha$
```lean
example : AddSubgroup ℚ where
  -- carrier = { y ∈ ℚ | ∃ x ∈ ℤ, f x = y}
  carrier := Set.range ((↑) : ℤ → ℚ)
  add_mem' := by
    rintro _ _ ⟨n, rfl⟩ ⟨m, rfl⟩
    use n + m
    simp
  zero_mem' := by
    use 0
    simp
  neg_mem' := by
    rintro _ ⟨n, rfl⟩
    use -n
    simp
```

Conjugation of a group $G$ is also a subgroup $H$, conjugation is defined as, $\text{Conj } h = x * h * x^{-1}$ where $x \in G$ and $h \in H$ :
```lean
def conjugate {G : Type*} [Group G] (x : G) (H : Subgroup G) : Subgroup G where
  carrier := {a : G | ∃ h, h ∈ H ∧ a = x * h * x⁻¹}
  one_mem' := by
    dsimp
    use 1
    constructor
    · exact H.one_mem
    · symm
      rw [mul_one, mul_inv_cancel]
  inv_mem' := by
    dsimp
    rintro x1 ⟨h, h_in, rfl⟩
    use h⁻¹, H.inv_mem h_in
    group
  mul_mem' := by
    dsimp
    rintro a b ⟨ha, ha_in, rfl⟩ ⟨hb, hb_in, rfl⟩
    use ha * hb, mul_mem ha_in hb_in
    group
```

### Definitions and Theorems 

*Map: if $G'$ is a subgroup of $G$, and $f$ is a group homomorphism $f : G \rightarrow H$, then the image of $f$ on $G'$ is a subgroup of $H$.*
```lean
example {G H : Type*} [Group G] [Group H] (G' : Subgroup G) (f : G →* H) : Subgroup H :=
  Subgroup.map f G'
```
In lean4, `Subgroup.map` works for it.

<br />

*Comap: if $H'$ is a subgroup of $H$, and $f$ is a group homomorphism $f : G \rightarrow H$, then the preimage of $f$ on $H'$ is a subgroup of $G$.*
```lean
example {G H : Type*} [Group G] [Group H] (H' : Subgroup H) (f : G →* H) : Subgroup G :=
  Subgroup.comap f H'
```
In lean4, `Subgroup.comap` works for it.

<br />

*Kernel: if $f$ is a group homomorphism $f : G \rightarrow H$, and one element $g \in G$ satisfies $f(g) = 1$ if and only if $g \in \ker f$.*
```lean
example {G H : Type*} [Group G] [Group H] (f : G →* H) (g : G) :
    g ∈ MonoidHom.ker f ↔ f g = 1 :=
  f.mem_ker
```

<br />

*Image: if $f$ is a group homomorphism $f : G \rightarrow H$, and one element $h \in H$ satisfies $\exist g \in G, f(g) = h$.*
```lean
example {G H : Type*} [Group G] [Group H] (f : G →* H) (h : H) :
    h ∈ MonoidHom.range f ↔ ∃ g : G, f g = h :=
  f.mem_range
```

<br />

*Map Order: if $f$ is a group homomorphism $f : G \rightarrow H$, $S$ and $T$ are two subgroups of $G$, and $S \le T$, then the images of $f$ on $S$ and $T$ satisfy $\text{map }f(S) \le \text{map }f(T)$.* 
```lean
example (φ : G →* H) (S T : Subgroup G) (hST : S ≤ T) : map φ S ≤ map φ T := by
  intro y y_in_map_S
  rw [mem_map]
  rcases y_in_map_S with ⟨x, x_in_comap_S, h⟩
  use x, hST x_in_comap_S, h
```

<br />

*Comap Order: if $f$ is a group homomorphism $f : G \rightarrow H$, $S$ and $T$ are two subgroups of $H$, and $S \le T$, then the preimages of $f$ on $S$ and $T$ satisfy $\text{comap }f(S) \le \text{comap }f(T)$.*
```lean
example (φ : G →* H) (S T : Subgroup H) (hST : S ≤ T) : comap φ S ≤ comap φ T := by
  intro x x_in_comap_S
  rw [mem_comap]
  exact hST x_in_comap_S
```

<br />

*Map Composition: if $\varphi$ is a group homomorphism $\varphi : G \rightarrow H$, and $\psi$ is a group homomorphism $\psi : H \rightarrow K$, and $S$ is a subgroup of $G$, then map composition $\psi \circ \varphi (S) = \psi(\varphi(S))$*
```lean
example (φ : G →* H) (ψ : H →* K) (S : Subgroup G) :
    map (ψ.comp φ) S = map ψ (S.map φ) := by
  ext x
  simp [mem_map]
```

<br />

*Comap Composition: if $\varphi$ is a group homomorphism $\varphi : G \rightarrow H$, and $\psi$ is a group homomorphism $\psi : H \rightarrow K$, and $U$ is a subgroup of $K$, then comap composition $(\psi \circ \varphi)^{-1} (U) = \varphi^{-1}(\psi^{-1}(U))$*
```lean
example (φ : G →* H) (ψ : H →* K) (U : Subgroup K) :
    comap (ψ.comp φ) U = comap φ (comap ψ U) := by
  ext x
  simp [mem_comap]
```

<br />

*Lagrange Theorem: if $G'$ is a subgroup of $G$, then the order of $G'$ divide that of $G$.*
```lean
example {G : Type*} [Group G] (G' : Subgroup G) : Nat.card G' ∣ Nat.card G :=
  ⟨G'.index, mul_comm G'.index _ ▸ G'.index_mul_card.symm⟩
```
Note that:
- `Nat.card G' ∣ Nat.card G` implies that exists $c$ such that `Nat.card G = Nat.card G' * c`, where `c` is the witness of the statement, and it equals `G'.index` which is the *index* of subgroup $G'$.
- `h ▸ e` means `rw [h] at e`
- `G'.index_mul_card.symm` means `- = G'.index * - `
- `mul_comm G'.index _` means `_ * G'.index`

<br />

*Sylow Theorem: if $p ^ n | G$, then there exists a subgroup $K$ of $G$ such that $|K| = p ^ n$.*
```lean
example {G : Type*} [Group G] [Finite G] (p : ℕ) {n : ℕ} [Fact p.Prime]
    (hdvd : p ^ n ∣ Nat.card G) : ∃ K : Subgroup G, Nat.card K = p ^ n :=
  Sylow.exists_subgroup_card_pow_prime p hdvd
```

<br />

*Quotient Group: if $H$ is a subgroup of $G$, and it is normal, then quotient $G / H$ is also a group.*
```lean
example {G : Type*} [Group G] (H : Subgroup G) [H.Normal] : Group (G ⧸ H) := inferInstance
```
proof sketched:

1. subgroup $H$ is normal means $h ∈ H, ∀ x ∈ G, x * h * x⁻¹ ∈ H$

*Group Equivalence: If $\varphi$ is a group homomorphism $G \rightarrow H$, then $G / \ker \varphi \simeq im(\varphi)$.*

example {G : Type*} [Group G] {M : Type*} [Group M] (φ : G →* M) :
    G ⧸ MonoidHom.ker φ →* MonoidHom.range φ :=
  QuotientGroup.quotientKerEquivRange φ

*Quotient Group Order: If $H$ and $K$ are two subgroups of $G$, and $|G| = |H| * |K|$, then $|G / H| = |K|$.*
```lean
lemma aux_card_eq [Finite G] (h' : Nat.card G = Nat.card H * Nat.card K) :
    Nat.card (G ⧸ H) = Nat.card K := by
  have := calc
    Nat.card (G ⧸ H) * Nat.card H = Nat.card G := by rw [← index_eq_card H, index_mul_card H]
    _                             = Nat.card K * Nat.card H := by rw [h', mul_comm]
  exact Nat.eq_of_mul_eq_mul_right Nat.card_pos this
```
we see that:
- `index_eq_card H` works for `H.index = Nat.card (G / H)`
- `index_mul_card H` works for `H.index * Nat.card H = Nat.card G`

*First Group Isomorphism Theorem: If $H$ and $K$ are two subgroups of $G$, $|G| = |H| * |K|$, and $H, G$ are disjoint. Then $K \simeq G / H$.*
```lean
-- The First Group Isomorphism Theorem
def iso₁ : K ≃* G ⧸ H := by
  -- if group homomorphism of `G ↦ G / H` is a bijective function on a subgroup `K` of `G`
  -- then `K ≃* G / H`
  apply MulEquiv.ofBijective ((QuotientGroup.mk' H).restrict K)
  rw [Nat.bijective_iff_injective_and_card]
  constructor
  · rw [← ker_eq_bot_iff, (QuotientGroup.mk' H).ker_restrict K]
    simp [h]
  · symm
    exact aux_card_eq h'
```
we see that:
- `MulEquiv.ofBijective` means `S = T`, iff the homomorphism $S \mapsto T$ is a bijective function
-  `QuotientGroup.mk' H` generates a group homomorphism $G \mapsto G / H$ 
- `Nat.bijective_iff_injective_and_card f` works for `Bijective f ↔ Injective f ∧ Surjective f` where `Surjective f ↔ card β = card α`
- `ker_eq_bot_iff` works `ker f = 1 ↔ Injective f`

*Second Group Isomorphism Theorem: If $H$ and $K$ are two subgroups of $G$, $|G| = |H| * |K|$, and $H, G$ are disjoint. Then $G \simeq (G / H) \times (G / K)$.* 
```lean
-- The Second Group Isomorphism Theorem
def iso₂ : G ≃* (G ⧸ K) × (G ⧸ H) := by
  -- Let `ϕ : G ↦ G / K` and `ψ : G ↦ G / H`
  -- then `ϕ × ψ : {(a, b) | x ∈ G, a ∈ ϕ x, b ∈ ψ x}`
  apply MulEquiv.ofBijective <| (QuotientGroup.mk' K).prod (QuotientGroup.mk' H)
  rw [Nat.bijective_iff_injective_and_card]
  constructor
  · rw [← ker_eq_bot_iff, ker_prod]
    simp [h.symm.eq_bot]
  · rw [Nat.card_prod]
    rw [aux_card_eq h', aux_card_eq (mul_comm (Nat.card H) _▸ h'), h']
```
we see that:
- if `ϕ : G ↦ G / K` and `ψ : G ↦ G / H`, then the product homomorphism `ϕ × ψ : {(a, b) | x ∈ G, a ∈ ϕ x, b ∈ ψ x}`

*Third Group Isomorphism Theorem: If $H$ and $K$ are two subgroups of $G$, $|G| = |H| * |K|$, and $H, G$ are disjoint. Then $G \simeq H \times K$.*
```lean
-- The Third Group Isomorphism Theorem
def finalIso : G ≃* H × K :=
  (iso₂ h h').trans ((iso₁ h.symm (mul_comm (Nat.card H) _ ▸ h')).prodCongr (iso₁ h h')).symm
```
proof skeched :

1. by the second group isomorphism theorem, reduce $G \simeq H \times K$ to $G \simeq (G / K) \times (G / H)$
2. by the first group isomorphism theorem and hypotheses, we have $(G / K) \times (G / H) \simeq H \times K$ 
3. by isomorphism transition, we obtain $G \simeq H \times K$
