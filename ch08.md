### General Group 

General group means the operator $\diamond$ is not specified concretely, it could be any binary operator.

**One Class**
```lean
class One₁ (α : Type) where
  /-- The element one -/
  one : α

@[inherit_doc]
notation "𝟙" => One₁.one

example {α : Type} [One₁ α] : α := 𝟙

example {α : Type} [One₁ α] : (𝟙 : α) = 𝟙 := rfl
```
One class, denoted as "𝟙",  is used to show the existence of identity, `1` for multplicative, and `0` for additive, note that $one \ne 1$. 

**Dia Class**
```lean
class Dia₁ (α : Type) where
  dia : α → α → α

infixl:70 " ⋄ "   => Dia₁.dia
```
Dia class, denoted as " ⋄ ", defines the function of binary operation closure $\alpha \rightarrow \alpha \rightarrow \alpha$.

**Semigroup Class**
```lean
class Semigroup₁ (α : Type) extends toDia₁ : Dia₁ α where
  /-- Diamond is associative -/
  dia_assoc : ∀ a b c : α, a ⋄ b ⋄ c = a ⋄ (b ⋄ c)
```
Semigroup class is used to define the associative property on operator " ⋄ ", so we need to extend Dia class first. 


**DiaOneClass Class**
```lean
class DiaOneClass₁ (α : Type) extends One₁ α, Dia₁ α where
  /-- One is a left neutral element for diamond. -/
  one_dia : ∀ a : α, 𝟙 ⋄ a = a
  /-- One is a right neutral element for diamond -/
  dia_one : ∀ a : α, a ⋄ 𝟙 = a
```
DiaOneClass class is specially used to define binary operation properties of " ⋄ " with identity element, so we also need to extend Dia class first.

**Monoid Class**

```lean
class Monoid₁ (α : Type) extends Semigroup₁ α, DiaOneClass₁ α
```
Monoid class is a combination of Semigroup and DiaOneClass, which has axioms:
- operation closure on " ⋄ " with type $\alpha \rightarrow \alpha \rightarrow \alpha$.
- identity and its operations, $1 \cdot a = a \cdot 1$.
- associative, $a \cdot b \cdot c = a \cdot (b \cdot c)$. 

**Inv Class**
```lean
class Inv₁ (α : Type) where
  /-- The inversion function -/
  inv : α → α

@[inherit_doc]
postfix:max "⁻¹" => Inv₁.inv
```
Inv class defines the inverse function $\alpha \rightarrow \alpha$.

**Group**
```
class Group₁ (G : Type) extends Monoid₁ G, Inv₁ G where
  inv_dia : ∀ a : G, a⁻¹ ⋄ a = 
```
Group class defines the inverse property $a^{-1} \cdot a = 1$, it is a function of $\alpha \rightarrow \alpha \rightarrow \alpha$ on " ⋄ ", and has inverse function $\alpha \rightarrow \alpha$ on $^{-1}$. 

### Addition Group

Addition group is an instance of the general group, where the diamond operator $\diamond$ is instanciated with $+$.

**AddSemigroup Class**
```
class AddSemigroup₃ (α : Type) extends Add α where
  /-- Addition is associative -/
  add_assoc₃ : ∀ a b c : α, a + b + c = a + (b + c)
```
*Add* is a concrete operator $+$ of the diamond $\diamond$, or an instance of `class Dia`. In this case, its corresponding instantiated semigroup is defined as `AddSemigroup` with instantiated associative $a + b + c = a + (b + c)$.

**Semigroup Class**
```lean
@[to_additive AddSemigroup₃]
class Semigroup₃ (α : Type) extends Mul α where
  /-- Multiplication is associative -/
  mul_assoc₃ : ∀ a b c : α, a * b * c = a * (b * c)
```
Semigroup is a multiplicative semigroup with default operator $*$. Note that, `to_additive AddSemigroup` means it will automatically generate a `AddSemigroup` class similar with `Semigroup`.

**AddMonoid Class**
```lean
class AddMonoid₃ (α : Type) extends AddSemigroup₃ α, AddZeroClass α
```
Similarly `AddMonoid` is an instance of `Monoid` with operator $+$, it also has to exend `AddSemigroup` and `AddZeroClass`. Where `AddZeroClass` is an instance of `DiaOneClass`.

**AddCommSemigroup Class**
```lean
class AddCommSemigroup₃ (α : Type) extends AddSemigroup₃ α where
  add_comm : ∀ a b : α, a + b = b + a
```
AddCommSemigroup define the commutative property of `AddSemigroup`.

**AddCommMonoid Class**
```lean
class AddCommMonoid₃ (α : Type) extends AddMonoid₃ α, AddCommSemigroup₃ α
```
AddCommMonoid is a combination of `AddMonoid`  and `AddCommSemigroup`.

**AddGroup Class**
```lean
class AddGroup₃ (G : Type) extends AddMonoid₃ G, Neg G where
  neg_add : ∀ a : G, -a + a = 0
```
AddGroup is an instance of group with operator $+$, similarly we need to extend `AddMonoid` and `Neg`, where `Neg` is an instance of `Inv` with operator $+$.

### Multiplicative Group

```lean
@[to_additive AddGroup₃]
class Group₃ (G : Type) extends Monoid₃ G, Inv G where
  inv_mul : ∀ a : G, a⁻¹ * a = 1
```
We can use `@[to_...]` to avoid dumplicate code.

### Additive Commutative Group 

Additive commutative group is an additive group with commutative property.

```lean
class AddCommGroup₃ (G : Type) extends AddGroup₃ G, AddCommMonoid₃ G
```
In this case, we need to inherit additive group property from `AddGroup` and commutative property from `AddCommMonoid`.

### Ring

Ring is composed of two components, one is object, the other one is scalar, both of them are defined by $R$ :
- the object is an additive group with operator $+$.
- the scalar is an monoid (no inverse) with operator $*$.
- operations on $*$ with zero will be absorbed into zero.
- mixed operations on $+$ and $*$ satisfy distributive property.

```lean
class Ring₃ (R : Type) extends AddGroup₃ R, Monoid₃ R, MulZeroClass R where
  /-- Multiplication is left distributive over addition -/
  left_distrib : ∀ a b c : R, a * (b + c) = a * b + a * c
  /-- Multiplication is right distributive over addition -/
  right_distrib : ∀ a b c : R, (a + b) * c = a * c + b * c
```

### Additive Commutative Group

Additive commutative group is a additive group with commutative property.

```
class AddCommGroup₃ (G : Type) extends AddGroup₃ G, AddCommMonoid₃ G

@[to_additive AddCommGroup₃]
class CommGroup₃ (G : Type) extends Group₃ G, CommMonoid₃ G


class Ring₃ (R : Type) extends AddGroup₃ R, Monoid₃ R, MulZeroClass R where
  /-- Multiplication is left distributive over addition -/
  left_distrib : ∀ a b c : R, a * (b + c) = a * b + a * c
  /-- Multiplication is right distributive over addition -/
  right_distrib : ∀ a b c : R, (a + b) * c = a * c + b * c

instance {R : Type} [Ring₃ R] : AddCommGroup₃ R :=
{
  add_comm := by
    intro a b
    have : a + (a + b + b) = a + (b + a + b) := calc
      a + (a + b + b) = (a + a) + (b + b) := by simp [add_assoc₃, add_assoc₃]
      _ = (1 * a + 1 * a) + (1 * b + 1 * b) := by simp
      _ = (1 + 1) * a + (1 + 1) * b := by simp [Ring₃.right_distrib]
      _ = (1 + 1) * (a + b) := by simp [Ring₃.left_distrib]
      _ = 1 * (a + b) + 1 * (a + b) := by simp [Ring₃.right_distrib]
      _ = (a + b) + (a + b) := by simp
      _ = a + (b + a + b) := by simp [add_assoc₃]
    exact add_right_cancel₃ (add_left_cancel₃ this)
}
```
Note that the object of Ring does not have additive commutative property, so we need to add it manually.

### Module

Module also consists of two components, one is an object, the other one is a scalar 
- the object $M$ is a additive commutative group (or additive abelian group) with operator $+$
- the scalar $R$ is a ring with operator $*$
- operations between object and scalar is often denoted as scalar-mul " • ", $\alpha \rightarrow \beta \rightarrow \beta$  :
    - $(a * b) \cdot m = a \cdot b \cdot m$
    - $(a + b) \cdot m = a \cdot m + b \cdot m$
    - $a \cdot (m + n) = a \cdot m + a \cdot n$

```lean
class SMul₃ (α : Type) (β : Type) where
  /-- Scalar multiplication -/
  smul : α → β → β

infixr:73 " • " => SMul₃.smul

class Module₁ (R : Type) [Ring₃ R] (M : Type) [AddCommGroup₃ M] extends SMul₃ R M where
  zero_smul : ∀ m : M, (0 : R) • m = 0
  one_smul : ∀ m : M, (1 : R) • m = m
  mul_smul : ∀ (a b : R) (m : M), (a * b) • m = a • b • m
  add_smul : ∀ (a b : R) (m : M), (a + b) • m = a • m + b • m
  smul_add : ∀ (a : R) (m n : M), a • (m + n) = a • m + a • n
```

For example, we can take `SMul = Ring * Ring`:
```lean
instance selfModule (R : Type) [Ring₃ R] : Module₁ R R where
  smul := fun r s ↦ r*s
  zero_smul := zero_mul
  one_smul := one_mul
  mul_smul := mul_assoc₃
  add_smul := Ring₃.right_distrib
  smul_add := Ring₃.left_distrib
```
that is to say, the object is define in `AdditiveCommGroup Ring`, and the scalar is defined in `Ring`.
