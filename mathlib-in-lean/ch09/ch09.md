## Group

Let's see an example of `Monoid` (with operator $*$) homomorphism, which denoted as $M \rightarrow* N$
```lean
example {M N : Type*} [Monoid M] [Monoid N] (x y : M) (f : M →* N) : f (x * y) = f x * f y :=
  f.map_mul x y
```

and an example of Abelian group (also `AddCommGroup`),
```lean
example {G : Type*} [AddCommGroup G] (x y z : G) : z + x + (y - z - x) = y := by
  abel
```

### Group Homomorphism
The definition of group homomorphism is, if a function $f : G \rightarrow H$ satisfy $f (x * y) = f(x) * f(y)$, then we say `f` is a group homomorphism:
```lean
example {G H : Type*} [Group G] [Group H] (f : G → H) (h : ∀ x y, f (x * y) = f x * f y) :
    G →* H :=
  MonoidHom.mk' f h
```
Notice that, `MonoidHom.mk` means making an monoid homomorphism (with a function `f` and hypothese `h` that `f(x * y) = f(x) * f(y)`).

### Group Isomorphism
If a group homomorphism $f : G \rightarrow *H$ is a bijective function, then we say `f` is a group isomorphism:
```lean
noncomputable example {G H : Type*} [Group G] [Group H]
    (f : G →* H) (h : Function.Bijective f) :
    G ≃* H :=
  MulEquiv.ofBijective f h
```
### Subgroup

Let's see an example of subgroup, $\mathbb{Z}$  is a subgroup of $\mathbb{Q}$. Subgroup needs to satisfy four conditions:
1. coercion function $\mathbb{Z} \rightarrow \mathbb{Q}$, that is any element from $\mathbb{Z}$ can be converted to $\mathbb{Q}$, i.e. $a \in \mathbb{Z}, (a : \mathbb{Q}) = a$ 
2. identity existence, since subgroup is also a group. $0$ for `AddGroup` and $1$ for `Group`
3. inverse, same reason. $-a$ for `AddGroup` and $a^{-1}$ for `Group`
4. addition (or multiplication) closure, $\alpha \rightarrow \alpha \rightarrow \alpha$
```lean
example : AddSubgroup ℚ where
  -- carrier = { y ∈ ℚ | ∃ x ∈ ℤ, f x = y}
  carrier := Set.range ((↑) : ℤ → ℚ)
  add_mem' := by
    rintro _ _ ⟨n, rfl⟩ ⟨m, rfl⟩
    use n + m
    simp
  zero_mem' := by
    use 0
    simp
  neg_mem' := by
    rintro _ ⟨n, rfl⟩
    use -n
    simp
```

Conjugation of a group $G$ is also a subgroup $H$, conjugation is defined as, $\text{Conj } h = x * h * x^{-1}$ where $x \in G$ and $h \in H$ :
```lean
def conjugate {G : Type*} [Group G] (x : G) (H : Subgroup G) : Subgroup G where
  carrier := {a : G | ∃ h, h ∈ H ∧ a = x * h * x⁻¹}
  one_mem' := by
    dsimp
    use 1
    constructor
    · exact H.one_mem
    · symm
      rw [mul_one, mul_inv_cancel]
  inv_mem' := by
    dsimp
    rintro x1 ⟨h, h_in, rfl⟩
    use h⁻¹, H.inv_mem h_in
    group
  mul_mem' := by
    dsimp
    rintro a b ⟨ha, ha_in, rfl⟩ ⟨hb, hb_in, rfl⟩
    use ha * hb, mul_mem ha_in hb_in
    group
```

### Definitions and Theorems 

*Map: if $G'$ is a subgroup of $G$, and $f$ is a group homomorphism $f : G \rightarrow H$, then the image of $f$ on $G'$ is a subgroup of $H$.*
```lean
example {G H : Type*} [Group G] [Group H] (G' : Subgroup G) (f : G →* H) : Subgroup H :=
  Subgroup.map f G'
```
In lean4, `Subgroup.map` works for it.

<br />

*Comap: if $H'$ is a subgroup of $H$, and $f$ is a group homomorphism $f : G \rightarrow H$, then the preimage of $f$ on $H'$ is a subgroup of $G$.*
```lean
example {G H : Type*} [Group G] [Group H] (H' : Subgroup H) (f : G →* H) : Subgroup G :=
  Subgroup.comap f H'
```
In lean4, `Subgroup.comap` works for it.

<br />

*Kernel: if $f$ is a group homomorphism $f : G \rightarrow H$, and one element $g \in G$ satisfies $f(g) = 1$ if and only if $g \in \ker f$.*
```lean
example {G H : Type*} [Group G] [Group H] (f : G →* H) (g : G) :
    g ∈ MonoidHom.ker f ↔ f g = 1 :=
  f.mem_ker
```

<br />

*Image: if $f$ is a group homomorphism $f : G \rightarrow H$, and one element $h \in H$ satisfies $\exist g \in G, f(g) = h$.*
```lean
example {G H : Type*} [Group G] [Group H] (f : G →* H) (h : H) :
    h ∈ MonoidHom.range f ↔ ∃ g : G, f g = h :=
  f.mem_range
```

<br />

*Map Order: if $f$ is a group homomorphism $f : G \rightarrow H$, $S$ and $T$ are two subgroups of $G$, and $S \le T$, then the images of $f$ on $S$ and $T$ satisfy $\text{map }f(S) \le \text{map }f(T)$.* 
```lean
example (φ : G →* H) (S T : Subgroup G) (hST : S ≤ T) : map φ S ≤ map φ T := by
  intro y y_in_map_S
  rw [mem_map]
  rcases y_in_map_S with ⟨x, x_in_comap_S, h⟩
  use x, hST x_in_comap_S, h
```

<br />

*Comap Order: if $f$ is a group homomorphism $f : G \rightarrow H$, $S$ and $T$ are two subgroups of $H$, and $S \le T$, then the preimages of $f$ on $S$ and $T$ satisfy $\text{comap }f(S) \le \text{comap }f(T)$.*
```lean
example (φ : G →* H) (S T : Subgroup H) (hST : S ≤ T) : comap φ S ≤ comap φ T := by
  intro x x_in_comap_S
  rw [mem_comap]
  exact hST x_in_comap_S
```

<br />

*Map Composition: if $\varphi$ is a group homomorphism $\varphi : G \rightarrow H$, and $\psi$ is a group homomorphism $\psi : H \rightarrow K$, and $S$ is a subgroup of $G$, then map composition $\psi \circ \varphi (S) = \psi(\varphi(S))$*
```lean
example (φ : G →* H) (ψ : H →* K) (S : Subgroup G) :
    map (ψ.comp φ) S = map ψ (S.map φ) := by
  ext x
  simp [mem_map]
```

<br />

*Comap Composition: if $\varphi$ is a group homomorphism $\varphi : G \rightarrow H$, and $\psi$ is a group homomorphism $\psi : H \rightarrow K$, and $U$ is a subgroup of $K$, then comap composition $(\psi \circ \varphi)^{-1} (U) = \varphi^{-1}(\psi^{-1}(U))$*
```lean
example (φ : G →* H) (ψ : H →* K) (U : Subgroup K) :
    comap (ψ.comp φ) U = comap φ (comap ψ U) := by
  ext x
  simp [mem_comap]
```

<br />

*Lagrange Theorem: if $G'$ is a subgroup of $G$, then the order of $G'$ divide that of $G$.*
```lean
example {G : Type*} [Group G] (G' : Subgroup G) : Nat.card G' ∣ Nat.card G :=
  ⟨G'.index, mul_comm G'.index _ ▸ G'.index_mul_card.symm⟩
```
Note that:
- `Nat.card G' ∣ Nat.card G` implies that exists $c$ such that `Nat.card G = Nat.card G' * c`, where `c` is the witness of the statement, and it equals `G'.index` which is the *index* of subgroup $G'$.
- `h ▸ e` means `rw [h] at e`
- `G'.index_mul_card.symm` means `- = G'.index * - `
- `mul_comm G'.index _` means `_ * G'.index`

<br />

*Sylow Theorem: if $p ^ n | G$, then there exists a subgroup $K$ of $G$ such that $|K| = p ^ n$.*
```lean
example {G : Type*} [Group G] [Finite G] (p : ℕ) {n : ℕ} [Fact p.Prime]
    (hdvd : p ^ n ∣ Nat.card G) : ∃ K : Subgroup G, Nat.card K = p ^ n :=
  Sylow.exists_subgroup_card_pow_prime p hdvd
```

<br />

*Quotient Group: if $H$ is a subgroup of $G$, and it is normal, then quotient $G / H$ is also a group.*
```lean
example {G : Type*} [Group G] (H : Subgroup G) [H.Normal] : Group (G ⧸ H) := inferInstance
```
proof sketched:

1. subgroup $H$ is normal means $h ∈ H, ∀ x ∈ G, x * h * x⁻¹ ∈ H$
2. quotient $G / H$ is a group means, $a₁, a₂ ∈ G, a₁ * H ∈ G / H, a₂ * H ∈ G / H → (a₁ * H) * (a₁ * H) = (a₁ * a₂) * H ∈ G / H$
3. $a₁ * H * (a₂ * H) = a₁ * a₂ * (a₂⁻¹ * H * a₂) * H = a₁ * a₂ * H$ since by normalization of $H$ we have $a₂⁻¹ * H * a₂ ∈ H$

<br />

*Group Equivalence: If $\varphi$ is a group homomorphism $G \rightarrow H$, then $G / \ker \varphi \simeq im(\varphi)$.*
```lean
example {G : Type*} [Group G] {M : Type*} [Group M] (φ : G →* M) :
    G ⧸ MonoidHom.ker φ →* MonoidHom.range φ :=
  QuotientGroup.quotientKerEquivRange φ
```

<br />

*Quotient Group Order: If $H$ and $K$ are two subgroups of $G$, and $|G| = |H| * |K|$, then $|G / H| = |K|$.*
```lean
lemma aux_card_eq [Finite G] (h' : Nat.card G = Nat.card H * Nat.card K) :
    Nat.card (G ⧸ H) = Nat.card K := by
  have := calc
    Nat.card (G ⧸ H) * Nat.card H = Nat.card G := by rw [← index_eq_card H, index_mul_card H]
    _                             = Nat.card K * Nat.card H := by rw [h', mul_comm]
  exact Nat.eq_of_mul_eq_mul_right Nat.card_pos this
```
we see that:
- `index_eq_card H` works for `H.index = Nat.card (G / H)`
- `index_mul_card H` works for `H.index * Nat.card H = Nat.card G`


<br />

*First Group Isomorphism Theorem: If $H$ and $K$ are two subgroups of $G$, $|G| = |H| * |K|$, and $H, G$ are disjoint. Then $K \simeq G / H$.*
```lean
-- The First Group Isomorphism Theorem
def iso₁ : K ≃* G ⧸ H := by
  -- if group homomorphism of `G ↦ G / H` is a bijective function on a subgroup `K` of `G`
  -- then `K ≃* G / H`
  apply MulEquiv.ofBijective ((QuotientGroup.mk' H).restrict K)
  rw [Nat.bijective_iff_injective_and_card]
  constructor
  · rw [← ker_eq_bot_iff, (QuotientGroup.mk' H).ker_restrict K]
    simp [h]
  · symm
    exact aux_card_eq h'
```
we see that:
- `MulEquiv.ofBijective` means `S = T`, iff the homomorphism $S \mapsto T$ is a bijective function
-  `QuotientGroup.mk' H` generates a group homomorphism $G \mapsto G / H$ 
- `Nat.bijective_iff_injective_and_card f` works for `Bijective f ↔ Injective f ∧ Surjective f` where `Surjective f ↔ card β = card α`
- `ker_eq_bot_iff` works `ker f = 1 ↔ Injective f`

<br />

*Second Group Isomorphism Theorem: If $H$ and $K$ are two subgroups of $G$, $|G| = |H| * |K|$, and $H, G$ are disjoint. Then $G \simeq (G / H) \times (G / K)$.* 
```lean
-- The Second Group Isomorphism Theorem
def iso₂ : G ≃* (G ⧸ K) × (G ⧸ H) := by
  -- Let `ϕ : G ↦ G / K` and `ψ : G ↦ G / H`
  -- then `ϕ × ψ : {(a, b) | x ∈ G, a ∈ ϕ x, b ∈ ψ x}`
  apply MulEquiv.ofBijective <| (QuotientGroup.mk' K).prod (QuotientGroup.mk' H)
  rw [Nat.bijective_iff_injective_and_card]
  constructor
  · rw [← ker_eq_bot_iff, ker_prod]
    simp [h.symm.eq_bot]
  · rw [Nat.card_prod]
    rw [aux_card_eq h', aux_card_eq (mul_comm (Nat.card H) _▸ h'), h']
```
we see that:
- if `ϕ : G ↦ G / K` and `ψ : G ↦ G / H`, then the product homomorphism `ϕ × ψ : {(a, b) | x ∈ G, a ∈ ϕ x, b ∈ ψ x}`

<br />

*Third Group Isomorphism Theorem: If $H$ and $K$ are two subgroups of $G$, $|G| = |H| * |K|$, and $H, G$ are disjoint. Then $G \simeq H \times K$.*
```lean
-- The Third Group Isomorphism Theorem
def finalIso : G ≃* H × K :=
  (iso₂ h h').trans ((iso₁ h.symm (mul_comm (Nat.card H) _ ▸ h')).prodCongr (iso₁ h h')).symm
```
proof skeched :

1. by the second group isomorphism theorem, reduce $G \simeq H \times K$ to $G \simeq (G / K) \times (G / H)$
2. by the first group isomorphism theorem and hypotheses, we have $(G / K) \times (G / H) \simeq H \times K$ 
3. by isomorphism transition, we obtain $G \simeq H \times K$

## Ring

### Few Facts

*Fact1: The unit of $\mathbb{Z}$ is either $1$ or $-1$.*
```lean
example (x : ℤˣ) : x = 1 ∨ x = -1 := Int.units_eq_one_or x
```

<br />

*Fact2: `Monoid` is multiplicative in default, so a unit `x` multiply its inverse equals 1.*
```lean
example {M : Type*} [Monoid M] (x : Mˣ) : (x : M) * x⁻¹ = 1 := Units.mul_inv x
```

<br />

*Fact3: The set of unit in `Monoid` forms a (multiplicative) group.*
```lean
example {M : Type*} [Monoid M] : Group Mˣ := inferInstance
```

<br />

*Fact4: If `f` is a ring homomorphism $R \rightarrow +* S$, then there must exists an homomorphism between the units of these two rings.*
```lean
example {R S : Type*} [Ring R] [Ring S] (f : R →+* S) : Rˣ →* Sˣ :=
  Units.map f
```

<br />

*Fact5: If `I` is an ideal of a ring, then there must exist a homomorphism between the ring and its quotient ring on ideal `I`.*
```lean
example {R : Type*} [CommRing R] (I : Ideal R) : R →+* R ⧸ I :=
  Ideal.Quotient.mk I
```
Notice that, `Ideal.Quotient.mk` means making a quotient (ring) homomorphism with an ideal. It is similar with `QuotientGroup.mk`, `MonoidHom.mk`, etc ....

<br />

*Fact6: If `I` is an ideal of a ring, and any element from `I` will be mapped to `0`.*
```lean
example {R : Type*} [CommRing R] {a : R} {I : Ideal R} :
    Ideal.Quotient.mk I a = 0 ↔ a ∈ I :=
  Ideal.Quotient.eq_zero_iff_mem
```
We see that:
- since `Ideal.Quotient.mk I` is `R → +* (R / I)`, if `(Ideal.Quotient.mk I) a = 0`, then `a ∈ I`

<br />

*Fact7: If `R` and `S` are two commutative rings, and `I` is an ideal of `R`, and `f` is an ring homomorphism $R \rightarrow +*S$. If `I` is an subset of the kernel of `f`, then there exists a quotient ring lift $R / I \rightarrow +* S$* 
```lean
example {R S : Type*} [CommRing R] [CommRing S] (I : Ideal R) (f : R →+* S)
    (H : I ≤ RingHom.ker f) : R ⧸ I →+* S :=
  Ideal.Quotient.lift I f H
```

<br />

*Fact8: if `R` and `S` are two commutative rings, `f` is an ring homomorphism $R \rightarrow +*S$. Then there exsits an ring isomorphism $R / \ker f \simeq im(f)$.*
```lean
example {R S : Type*} [CommRing R] [CommRing S](f : R →+* S) :
    R ⧸ RingHom.ker f ≃+* f.range :=
  RingHom.quotientKerEquivRange f
```

<br />

*Fact9: If `I` and `J` are two ideals of commutative ring `R`, then any element from `I + J` can be represented as sum of two elements from `I` and `J` individually.*
```lean
example {x : R} : x ∈ I + J ↔ ∃ a ∈ I, ∃ b ∈ J, a + b = x := by
  simp [Submodule.mem_sup]
```

<br />

*Fact10: If `I` and `J` are two ideals of commutative ring `R`, then the product `I * J` is contained in `J`.*
```lean
example : I * J ≤ J := Ideal.mul_le_left
```
Proof: By the definition of ideal multiplication, $\forall x \in R, x * J \in J$, and $I \subset R$, so we must have $\forall x \in I, x * J \in J$.

<br />

*Fact11: If `I` and `J` are two ideals of commutative ring `R`, then the product `I * J` is contained in `I`.*

```lean
example : I * J ≤ I := Ideal.mul_le_right
```
Proof : It is similar with the previous fact, since $\forall x \in R, I * x \in I$, and $J \subset R$, so we must have $\forall x \in J, I * x \in I$.

<br />

*Fact12: If `I` and `J` are two ideals of commutative ring `R`, then the product `I * J` is contained in the intersection of `I` and `J`.*

```lean
example : I * J ≤ I ⊓ J := Ideal.mul_le_inf
```
Proof : By the definition of ideal multiplication, $\forall x \in R, x * J \in J$, and $I \subset R$, so we must have $\forall x \in I, x * J \in J$. Similarly, $\forall y \in R, I * y \in I$, and $J \subset R$, so we must have $\forall y \in J, I * y \in I$. Therefore, $\forall z \in I * J$, we have $z \in I$ and $z \in J$, which means $z \in I ⊓ J$.

<br />

*Fact13: If `I` and `J` are two ideals of commutative ring `R`, and `f` is an ring homomorphism $R \rightarrow +*S$. If `I` is contained in the preimage of `J` under `f`, then there exists a quotient ring lift $R / I \rightarrow +* S / J$*

```lean
example {R S : Type*} [CommRing R] [CommRing S] (I : Ideal R) (J : Ideal S) (f : R →+* S)
    (H : I ≤ Ideal.comap f J) : R ⧸ I →+* S ⧸ J :=
  Ideal.quotientMap J f H
```

Proof : By the definition of comap, $\forall x \in I, f(x) \in J$, which means $f(I) \subseteq J$. Therefore, we can define a quotient ring lift $R / I \rightarrow +* S / J$ by sending each coset $x + I$ to the coset $f(x) + J$. This is well-defined because if $x + I = y + I$, then $x - y \in I$, and hence $f(x - y) = f(x) - f(y) \in J$, which implies that $f(x) + J = f(y) + J$.

<br />

*Fact14: If `I` and `J` are two ideals of commutative ring `R`, and `I = J`, then there exists a quotient ring isomorphism $R / I \simeq R / J$.*
```lean
example {R : Type*} [CommRing R] {I J : Ideal R} (h : I = J) : R ⧸ I ≃+* R ⧸ J :=
  Ideal.quotEquivOfEq h
```

Proof : Since $I = J$, the cosets of $I$ and $J$ are the same, and hence the quotient rings $R / I$ and $R / J$ are isomorphic. The isomorphism can be defined by sending each coset $x + I$ to the coset $x + J$. This is well-defined because if $x + I = y + I$, then $x - y \in I = J$, which implies that $x + J = y + J$. 

### Polynomial Ring

*Fact15: If `R` is a commutative ring, then the polynomial ring `R[X]` is also a commutative ring.*

```lean
-- `C r` is the constant polynomial with value `r`
example {R : Type*} [CommRing R] (r : R) := X - C r

-- `C` is the canonical embedding of `R` into `R[X]`, by ring homomorphism `R → R[X]` we have  `(C r)^2 = C (r ^ 2)`
example {R : Type*} [CommRing R] (r : R) : (X + C r) * (X - C r) = X ^ 2 - C (r ^ 2) := by
  rw [C.map_pow]
  rin

example {R : Type*} [CommRing R] (r:R) : (C r).coeff 0 = r := by simp

example {R : Type*} [CommRing R] : (X ^ 2 + 2 * X + C 3 : R[X]).coeff 1 = 2 := by simp
```
Notice that `C` is the canonical embedding of `R` into `R[X]`, by ring homomorphism `R → R[X]` we have  `(C r)^2 = C (r ^ 2)`. So the coefficient of the constant polynomial `C r` is `r`, and the coefficient of `X` in the polynomial `X ^ 2 + 2 * X + C 3` is `2`.

<br />

*Fact16: If `R` is a semiring with no zero divisors, and `p`, `q` are polynomials in `R[X]`, then the degree of their product is the sum of their degrees.*

```lean
example {R : Type*} [Semiring R] [NoZeroDivisors R] {p q : R[X]} :
    degree (p * q) = degree p + degree q :=
  Polynomial.degree_mul
```

<br />

*Fact17: If `R` is a semiring with no zero divisors, and `p`, `q` are polynomials in `R[X]`, then the degree of their composition is the product of their degrees.*

```lean
example {R : Type*} [Semiring R] [NoZeroDivisors R] {p q : R[X]} :
    natDegree (comp p q) = natDegree p * natDegree q :=
  Polynomial.natDegree_comp
```

<br />

*Fact18: If `R` is a commutative ring, and `p` is a polynomial in `R[X]`, then the evaluation of `p` at `x` is also an element of `R`.*

```lean
example {R : Type*} [CommRing R] (P: R[X]) (x : R) := P.eval x
```

<br />

*Fact19: If `R` is a commutative ring, and `p` is a polynomial in `R[X]`, then `r` is a root of `p` if and only if the evaluation of `p` at `r` is zero.*

```lean
example {R : Type*} [CommRing R] (P : R[X]) (r : R) : IsRoot P r ↔ P.eval r = 0 := Iff.rf
```

<br />

*Fact20: If `R` is a commutative ring with no zero divisors, and `r` is an element of `R`, then the roots of the polynomial `X - C r` are exactly the singleton set containing `r`.*

```lean
example {R : Type*} [CommRing R] [IsDomain R] (r : R) : (X - C r).roots = {r} :=
  roots_X_sub_C r
```

Proof : The polynomial `X - C r` has exactly one root, which is `r`. This follows from the fact that if `X - C r = 0`, then `X = C r`, and hence the only solution is `r`.

<br />

**Note that `IsDomain R` means `R` is a commutative ring with no zero divisors, also known as an integral domain. `IsDomain` is necessary for `.roots` since `.roots` relies on the theorem that a non-zero polynomial of degree `n` has at most `n` roots in an integral domain.**

<br />

*Fact21: If `R` is a commutative ring with no zero divisors, and `r` is an element of `R`, and `n` is a natural number, then the roots of the polynomial `(X - C r) ^ n` are exactly the multiset containing `r` with multiplicity `n`.*

```lean
example {R : Type*} [CommRing R] [IsDomain R] (r : R) (n : ℕ):
    ((X - C r) ^ n).roots = n • {r} :=
  by simp
```

Note that `.roots` returns a multiset of roots, and `n • {r}` denotes the multiset containing `r` with multiplicity `n`, where `•` is `SMul` operator.

<br />
